Album names

Pick the name each album should have in Immich. Folders are never renamed (an Immich external asset is identified by its path: renaming would create new assets and lose faces, albums and favorites). Instead, tools/apply_albumprops.py writes an .albumprops file with override_name for immich-folder-album-creator, in every album folder. The name is your custom name, else the Facebook title, else the folder name without its ID; when two albums would get the same name (the album creator would merge them), the account folder name or the album ID is added. Names are stored in {{ names.path or 'memory only (no writable data folder)' }}, which you can also edit by hand.
