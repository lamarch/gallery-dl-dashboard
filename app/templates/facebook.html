  1. On Facebook, open the account's Photos → Albums page and scroll to the very bottom so every album is loaded.
  2. Save it as “Web Page, Complete” (“HTML only” has no albums: Facebook draws them with JavaScript).
  3. Upload the .html file below (the _files folder is not needed). It is read in memory: only album IDs, titles and counts are kept, never the page (it can contain session tokens). Delete your saved copy afterwards.
